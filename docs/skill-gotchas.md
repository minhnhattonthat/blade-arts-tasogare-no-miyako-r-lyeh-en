# Skill gotchas

One line per gotcha: the skill reference file it belongs in, then the fact.

- scripts/sheet.py: `--crop` past the image (y 300 on a 320x240 frame) dies with struct.error in write_png, no clear message; PCSX-Redux frames switch between 320x240 and 320x480 within one run (the title is 480i).
- graphics.md §Edit: the same TIM pixels can sit in two files under different CLUTs (Blade Arts G6 "Prestage" in M02_10_0 vs M03_01_0): map AA levels to indices per palette by luminance (`tools/gfx_draw.py ramp_text`), never one index ramp for both.

- platform-ps1.md: Blade Arts script text (DATA/SOL.SRP) is Shift-JIS XORed with 0x8C, so a raw SJIS scan of the disc finds only item names and menus; find it by dumping RAM while text shows, then searching the disc for the bytes next to the decoded text (here a string-offset table).
- platform-ps1.md: on this game's title screen circle confirms and cross does nothing, so `--mash-key cross` idles into the attract demo; check which button confirms before mashing.
- graphics.md §Survey: a TIM sweep drawn with each TIM's first CLUT hid Japanese twice here (stage-clear card and "on sale summer 2000" screen had all-black first CLUTs; some TIMs are flagged 16bpp over 4bpp data and draw as noise); re-draw every near-black or noisy TIM with palette indices as grey (`tools/timsweep.py --gray`). Dedup identical TIMs across map packs first (1525 -> 157 here).
- emulator-qa.md §Debug tool: grep the EXE for the map-file format string (`M%02d_%02d_%x`) and for leftover debug-menu strings first: here they gave the current-map variable (via the format call) and a full stage/event/boss list in minutes; a "SELECT Stage" menu drawn with FntPrint is invisible in a retail build, so reuse its data, not its screen.
- emulator-qa.md §Debug tool (PS1): forcing a top-level program/overlay switch from the field reset the console (PC 0xBFC00000) while the same request from the title worked; when an emu.py run "times out" with frames stopped, register an `ExecutionFlow::Pause` listener that logs the PC: a pause at 0xBFC00000 is a crash-reset, not a slow load.
- emulator-qa.md §emu.py: `--var MASH=...` is rejected (driver global); a warp script that needs its own circle-mash must use another name, and emu.py's `--mash` fires during boot too, before the warp.
- emulator-qa.md §Per-emulator (PCSX-Redux): the title menu's default cursor (Continue vs New Game) can depend on the memory card; give every scripted run its own card (`--sav` blank) instead of the portable card beside the exe.
- emulator-qa.md: a boot route timed from a play.py session's savestate is not frame-exact from a cold boot (the play state was taken late); retime routes on a cold `emu.py --sheet` run.
- pipeline.md §Extract: a raw-text scanner that starts strings only after a NUL missed strings that sit right after a pointer table (STATUS.BIN 0x748); start a candidate at every referenced address too, and let the coverage test (every kana run inside an extracted string) find the rest: it also caught a stray 0B byte mid-line and a halfwidth-kana debug string the first scanner rejected.
- platform-ps1.md: to find an overlay's load address, dump RAM while it runs (`ramdump.lua`) and search the dump for 32-byte chunks of the file; static guesses from pointer histograms were ambiguous here (4 overlays share one slot, 0x80149800).
- platform-ps1.md: unicorn (2.1, MIPS) can't fetch from a region mapped at 0x80000000; map RAM at 0 and strip the kseg0 bit on mem_write/mem_read (wrapper object, not a Uc subclass: subclassing breaks `_uch`). Its mem_map raises a handled access violation on Windows that pytest's faulthandler prints as a crash: run pytest with `-p no:faulthandler`.
- platform-ps1.md: when every free-looking EXE zero run turns out to be BSS (crt0 clears from inside the EXE image), look for dead data instead: a leftover debug menu's record table (read only by an unreachable game mode) gave 8 KB for hook code; prove it with lui-xrefs plus RAM dumps from many scenes.
- emulator-qa.md: a text-window probe hooked at the renderer's open function (exec bp, needs `--debugger`) logs every window's geometry per string; menu screens reopen their windows every frame, so the log grows by thousands of lines per scene.
- pipeline.md §Marker: a game font may fill cells past its last glyph with a filler pattern rather than zeros; check free glyph slots against that pattern, not against empty.
- emulator-qa.md: a marker build that rewrites save/load strings can break loading: games compare the memory-card title prefix against a string table (Blade Arts LOADSAVE 0x6D0/0xBDC); bisect the save-menu strings with --qa overrides when load scenes fail only on the patched build.
- Claude Code Edit tool: a new_string ending in a tab loses that tab (TSV cell edits): end the edit on the next cell's text.
- graphics.md §Lettering: a PS1 TIM whose CLUT is all 0x8000 (Blade Arts stage cards) gets its real palette at run time, here a shuffled ramp, a different one per sprite row; lettering by the TIM's index order gives hollow letters. Recover it by aligning the TIM with a JP screenshot and averaging the colour per index (`tools/clutfit.py`; candidate for `scripts/`).
- Any TSV: Python `csv.writer` with default quoting rewrites a field holding a mid-field `"` as quoted with doubled quotes; read and append with `quoting=csv.QUOTE_NONE`, or write lines with a tab join.
- graphics.md §Lettering: one PS1 TIM can be drawn with several CLUTs (Blade Arts staff roll: its own for most groups, two runtime ones for others); lines that look garbled in the TIM-CLUT preview are the tell. Fit each group with a CLUT fit on a JP shot, and learn sprite rects from a marker build (dot grid over the background pixels) before deciding how wide English may run.
- emulator-qa.md §Text coverage: on a game whose dialogue is map events, a warp-and-mash event tour covered 87 of 3643 strings in hours (events need story triggers). Swapping each message in at the game's own message lookup from one savestate (copy the target sector into the game's buffer, set the index register; PCSX.loadSaveState inside L.on_frame per message) showed all of them in ~40 min: Blade Arts tools/solview.py + tools/lua/solview.lua. Worth a generic recipe.
- emulator-qa.md §Visual QA: a cutscene host may never pass the pad to its text window, so circle presses don't turn pages; OR the window's own confirm mask into the pad register at the wait check (exec hook) instead of pressing.
- references/translation.md §Review (codex exec): codex can be out of quota for days ("usage limit ... try again at <date>"); a worker then has no independent reviewer and must review sheets itself, so pack sheets densely (1:1 crops of the text rows, 60 per sheet).
- references/emulator-qa.md: a VWF that spends one glyph record per letter can overrun a window's per-window record cap (PS1 Blade Arts: cap at window+0x30, 45 for item descriptions) and silently cut text; solview-style forced display of every raw string (tools/rawview.py) found it where width lints could not. Check record caps, not only pixel width.
